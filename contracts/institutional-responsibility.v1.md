# Institutional responsibility v1

## Purpose

Describe **possible** duty-to-institution patterns for human review. Never auto-contact government.

## Rules

- Recommendations only; human approval required for any consequential action
- Jurisdiction uncertainty must be explicit
- No invented contacts, offices, laws, or performance scores
- Publication of a civic demand does not assign legal liability

## Accountability stages (Observatory)

Referral → Acknowledgement → Announcement → Implementation → Independent verification  
Each stage requires its own evidence type. AI text cannot promote a stage alone.
